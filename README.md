# testmuai-selenium-java-automation

End-to-end UI test automation project built with Selenium, Java, and TestMu AI execution.

---

## 🚀 Features
* **Selenium WebDriver:** Robust and scalable browser automation.
* **Java (JDK 11+):** Core programming language for test scripts.
* **TestMu AI Integration:** Optimized for running automated test suites seamlessly on cloud infrastructure.
* **Maven / Gradle:** Easy dependency management and build execution.
* **Page Object Model (POM):** Clean architecture separating test scripts from page locators.

---

## 🛠️ Prerequisites
Before running the project, make sure you have the following installed:
* **Java Development Kit (JDK 11 or higher)**
* **Maven** (or Gradle, depending on your build tool)
* **IDE** (IntelliJ IDEA, Eclipse, or VS Code)
* **TestMu AI Account Credentials** (Username and Access Key)
